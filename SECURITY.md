# Security

Please **do not** open a public issue for a security problem. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Relevant areas include rules files, journals or folder layouts that make the tool move files outside the chosen
folder, replace or delete a file, or follow a symbolic link, and anything that would send data off your computer.

This is a volunteer project; expect an initial reply within about two weeks.
